Principios de layout

  • Usar una retícula consistente y alineaciones claras.
  • Priorizar espacios en blanco para facilitar la lectura.
  • Limitar el ancho de párrafos largos para mejorar legibilidad.
  • En móvil, apilar columnas y mantener controles cómodos para el tacto.
  • Usar sombras sutiles; evitar efectos 3D y degradados en la identidad principal.
06 / Aplicación

Uso correcto de la marca

✓ Recomendado

  • Respetar los colores y proporciones originales.
  • Dejar espacio libre alrededor del logo.
  • Usar el isotipo cuando el espacio sea reducido.
  • Garantizar contraste suficiente con el fondo.
  • Usar versiones monocromáticas solo si el medio lo exige.

✕ Evitar

  • Estirar, comprimir o inclinar el logotipo.
  • Cambiar el naranja por otros tonos sin criterio.
  • Agregar sombras, biseles o degradados al logo.
  • Colocar el logo sobre fondos con poco contraste.
  • Separar o reordenar las letras del nombre.
